# Fontanería Alborán
Propuesta de web estática multipágina. Abrir index.html o servir la carpeta con un servidor estático.
## Funciones
Servicios, inspiración, empresa, presupuesto guiado por WhatsApp y panel de demostración local con agenda, estados y notas. Logo SVG en dos variantes.
## Publicación definitiva
Validar teléfono, alcance de servicios y cobertura con el negocio. Incorporar datos fiscales y textos legales definitivos. Sustituir fotografías de inspiración por obras autorizadas. El panel de demo no es un backend de producción.
